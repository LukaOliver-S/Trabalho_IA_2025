# Trabalho_IA_2025
O objetivo é que o robô colete 15 cubos distribuídos aleatoriamente pela arena. Para cada cubo encontrado, o robô deve pegá-lo com a garra, identificar sua cor (verde, azul ou vermelho) e depositá-lo na caixa de cor correspondente. Durante toda a operação, o robô deve navegar evitando os obstáculos no ambiente.
